## 🚀 Current Project — PharmaTrace

> **🔗 Blockchain-Powered Medicine Verification & Counterfeit Detection**

PharmaTrace tracks every drug unit from **manufacturer → distributor → pharmacy**, ensuring:
- ✅ End-to-end drug authenticity verification
- 🔍 Counterfeit detection using blockchain immutability
- 📦 Full supply chain transparency
- 💊 Patient safety at every touchpoint
